# ClearBank - Análise Financeira com Python

Projeto do desafio prático do módulo de Análise de Dados e Inteligência de Negócios da Rocketseat.

## O que o projeto faz

Lê um arquivo CSV com transações bancárias, valida os dados, agrupa por mês, calcula as métricas e exporta o resultado em JSON.

## Como executar

Abra o notebook no Google Colab ou Jupyter e rode as células em ordem.

Se for local, instale as dependências opcionais:
```
pip install pandas matplotlib
```

## Arquivos gerados

- `relatorio.json` - resultado da análise em JSON
